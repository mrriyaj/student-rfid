# 🎓 Student RFID System

🚀 **A smart RFID-based student management system for seamless attendance tracking and monitoring.**  
Enhance security, automate attendance, and streamline student record management with RFID technology.

---

## **✨ Features**
✅ **RFID-based Student Authentication** - Secure and quick identification.  
✅ **Automated Attendance Tracking** - Real-time attendance logging.  
✅ **Admin Dashboard** - View student records and analytics.  
✅ **Notifications & Reports** - Generate attendance reports efficiently.  
✅ **Easy Integration** - Works with existing school management systems.

---

## **📥 Installation & Setup**
1. Clone the repository:
   ```sh
   https://github.com/mrriyaj/student-rfid.git
   ```
2. Navigate to the project directory:
   ```sh
   cd student-rfid
   ```
3. Install dependencies:
   ```sh
   composer install
   npm install
   ```
4. Set up environment variables:
   ```sh
   cp .env.example .env
   ```
5. Run database migrations:
   ```sh
   php artisan migrate
   ```
6. Start the application:
   ```sh
   php artisan serve
   ```
